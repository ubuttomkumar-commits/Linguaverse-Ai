## Security & Architecture Non-Negotiables Checked
- **Zero Duplicate Architecture**: All improvements upgrade existing files (`LearnerShell`, `App`, `prd61Api`, `worker/index.ts`, `worker/routes/*`, `server/prd61Routes.ts`, `wrangler.toml`).
- **Strict Private Cache Hygiene**: Auth (`/api/v1/auth/*`), Admin (`/api/v1/admin/*`), Notifications (`/api/v1/notifications`), and Realtime SSE (`/api/v1/realtime/events`) MUST remain `Cache-Control: no-store, private`.
- **No Fake Real-Time Polling**: Realtime push uses genuine Server-Sent Events (`text/event-stream`) with event-driven pub-sub on Express and clean SSE framing on Cloudflare Worker, with documented Durable Objects hub upgrade path for multi-isolate Worker fan-out.
